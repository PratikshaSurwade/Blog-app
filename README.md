# Blog-app - A News Blog Website
Uses: Reactjs, React router dom, Mongodb, Nodejs, Expressjs
# Demo Site URL: 
https://m-e-r-n-blog-app.netlify.app/

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT (Authentication & Authorization)

---

## 🔐 Features

- User authentication & authorization using JWT
- Login & Register pages
- User profile page
- Product browsing (in progress)
- Order tracking (UI in progress)
- Responsive and modern UI with Tailwind CSS

---

## 📁 Project Structure

This repository contains **multiple folders** representing different stages of development:


### Folder Explanation

- **backend/**  
  Contains the server-side code built with Express and MongoDB, including authentication using JWT.

- **frontend/**  
  Initial frontend created using **Create React App (CRA)**.  
  This is no longer actively used and kept for reference.



---

## 🛠️ Installation & Setup

### Backend
```bash
cd backend
npm install
npm run server
```

### Frontend

```
cd client
npm install
npm run dev
```
App will run on: http://localhost:5173
